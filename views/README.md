
## 🛠️ Requirements

- [Visual Studio Code](https://code.visualstudio.com/)
- [Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)

## 🚀 Running the Game Locally

1. **Clone or download** this repository.
2. **Open the folder** in Visual Studio Code.
3. **Install Live Server** (if not already installed):
   - Go to the Extensions tab (Ctrl+Shift+X)
   - Search for **Live Server** by Ritwick Dey
   - Click **Install**
4. **Right-click `index.html`** in the file tree and select **"Open with Live Server"**.
5. The game will launch in your default browser.

## 🧠 Development Notes

- The game is written in **vanilla JavaScript** for simplicity and performance.
- Modular scripts can be placed under `/scripts/` if needed.
- Make sure your browser supports modern JavaScript (ES6+).
